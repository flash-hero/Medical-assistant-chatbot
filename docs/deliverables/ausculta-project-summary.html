Overview

Ausculta answers general health questions from trusted public sources, always with citations, and handles hospital front-desk requests: opening hours, departments, visiting rules and appointment requests. It works in English, French and Arabic, including Moroccan Darija written in Arabic script or in Latin letters (Arabizi), with a right-to-left interface. Answers are generated with the Gemini API on its free tier. Retrieval runs on a local embedding model, so the system has no per-query embedding cost and patient questions are never sent to an embedding service.

Design principle: safety before generation. Emergency and self-harm messages are detected deterministically, without any model, and answered first with emergency and crisis numbers. Every medical answer must be grounded in retrieved passages and verified before release; otherwise the assistant declines and refers the user to a professional. It never diagnoses, judges urgency or gives personal doses. Demo mode is on: not for real patients.

Output checks & verification
  • Data: 34,464 documents from 16 licence-checked sources (MedlinePlus, NIH institutes, NCI PDQ, CDC, openFDA, French and Arabic sources). A source registry enforces licences, excluded sources and the quarantine of injected text.
  • Retrieval: structure-aware chunking; EmbeddingGemma-300M (768-d, ONNX on CPU) with BM25 sparse vectors in Qdrant. Dense search was adopted after a measured comparison. A calibrated confidence gate drives abstention. Each corpus version is signed (HMAC manifest) and verified at startup.
  • Live index: 29,730 chunks: the English consumer-health core plus the FDA labels of 305 common medicines.
  • Guardrails: multilingual risk lexicons (EN/FR/AR, Darija, Arabizi); a Gemini guard classifier; prompt-injection defences (nonce-delimited data blocks, canary checks); verify-then-release; numeric grounding; claim, triage, phone and URL filters; PII redaction.
  • Service: streaming over SSE, Redis-backed sessions and locks, rate limits, admission control, a spend cap, a kill switch and idempotent appointment forms. Emergency turns survive a Redis outage.
  • Interface: accessible chat (WCAG checks, strict CSP), citations drawer, safety banner and appointment form.

Engineering challenges and how they were solved

ChallengeResolution
Gemini free tier allows only 1,000 embedded texts per day; no billing availableMoved embeddings to a local open model (EmbeddingGemma via ONNX), with no quota. Prioritised the English consumer-health core, then added drug labels for common medicines.
Limited laptop memory during indexingBatch embedding with an on-disk cache, detached low-priority jobs, capped container memory; indexing is resumable with no repeated work.
Medication questions always declinedCurated one FDA label per common medicine (salt- and combination-aware matching) and indexed only that subset.
First-token latency above targetThe query rewrite now runs concurrently with the guard classifier and is cancelled on non-medical paths: p95 dropped from 5.87 s to 2.96 s.
Hardening findings (11 in the bug hunt)Fixed Unicode smuggling in outputs, canary-leak variants, unsafe URI schemes, a French unhedged diagnosis, emergency handling during a Redis outage, a French/Arabizi false alarm and overload latency. Each fix has a regression test.
Production packagingFixed container issues one by one (model download permissions, config paths, proxy routing, missing migrations, unsigned corpus in the volume), giving a reproducible stack with a one-shot migration and a signed corpus loader.
Free hosting for a ~2 GB stack, with no cardHugging Face Docker Spaces became paid; Render and Koyeb offer 512 MB; Oracle requires a card. Repackaged the stack as one unprivileged container and deployed it on Modal's free tier with the corpus baked into the image. Fixed six platform issues along the way: module shadowing, root-owned files, supervisor log permissions and others.
CI never executed (invalid workflow)Repaired the workflow; the first real runs exposed an undeclared dependency, a WCAG 2.5.3 issue on the Arabic header and flaky tests. All fixed; CI fully green.

Deployment

  • Public demo at no cost and with no payment method on Modal (Starter plan, $1 of compute per month, scale-to-zero, about 35 s cold start). Hugging Face moved Docker Spaces to a paid plan, so the same image moved to Modal. The full stack runs in one container managed by supervisord: Caddy, Next.js, FastAPI, Qdrant, Redis and PostgreSQL, all services unprivileged. The image is built from a pinned GitHub commit. The signed corpus comes from a public GitHub release with source credits and is restored at build time; the API verifies its signature before answering. Verified live: emergency banner in 0.3 s, cited answers in EN/FR/AR.
  • Self-hosting: Docker Compose behind Caddy with automatic HTTPS, a hash-pinned dependency lock, health checks, migrations and a runbook. CI builds the images and checks that the stack starts healthy.

Limitations and next steps

  • Not a medical device. Demo mode stays on until clinician review, native-speaker review of the Arabic and Darija sets, the human data audit and the pilot sign-off are complete.
  • Free-tier constraints: evaluation samples are small and latency depends on the free Gemini tier. A paid tier would allow full-corpus indexing (French and Arabic sources) and production latency figures.
  • Tracked improvements: prefer oral consumer labels for drugs (#6); a clinician-reviewed caustic-substance entry for the keyword lexicon (#7).
