# ADR 0002: Retrieval configuration and the rerank decision (P3B, 2026-11-16, free tier, PROVISIONAL)

Status: accepted for the development seed; re-measure on the full build before release.

## Context

Retrieval must reach recall@20 >= 0.90 EN / 0.85 FR / 0.80 AR, retrieval p95 <= 400 ms, abstain on >= 90% of
out-of-corpus questions while abstaining on <= 10% of answerable ones (`evals/gates.yaml`). ADR 0001 left the
reranker open: `gemini-decision-1` relevance scoring is kept only if it gains >= 3 nDCG@8 points over RRF-only.

Everything below was measured on the free tier, on the development seed collection only, so every number is
**provisional**:

- Collection `ausculta_corpus_2026_11_16_seed1` (alias `ausculta_corpus`): 720 chunks from 327 MedlinePlus
  health-topic documents (A..Electrical Injuries), signed manifest.
- Gold set (`evals/retrieval/gold/`): 450 rows, 599 distinct query texts. 288 answerable (96 per language)
  + 162 out-of-corpus (54 per language). Generated by `gemini-3.5-flash-lite` from indexed passages
  (`gen_20261116T062632Z_*`) plus agent-written seed rows (`agent_seed1_*`). Status
  `llm_generated_unreviewed`: no clinician or native-speaker review yet. Each answerable row has exactly one
  relevant chunk. FR/AR rows carry an English rewrite (`search_queries`) written by the model WITHOUT the
  passage, as the production query rewriter would.
- Run: `python -m rag eval` (online, alias target, defaults: rerank sample 30 per language at 12 s pacing,
  20 embedding-latency samples, calibration written, resume check) at 2026-11-16 11:59 UTC, exit 0, 20 min.
  Report `reports/retrieval/20261116T115912Z.json`; gate records `reports/rag.metrics.json`.
  All 599 query vectors came from the query-embedding cache (0 new embeddings during the run).

Pipeline under test (`rag/retrieval.py`, `rag/search.py`): `gemini-embedding-2` 768-d query vector (one per
query text) + client-side BM25 (fastembed `Bm25`, one named sparse vector per language, Snowball stemming,
Arabic/Latin folding) on the query language and on the English rewrite; one Qdrant `query_batch_points`
round trip with RRF at an explicit k = 60 (server default is 2); deterministic tie order; at most 2 chunks per
document and one per parent section; parent-section expansion (900 tokens per passage, 6,000 total);
drug-synonym expansion (330 groups).

Two fidelity fixes landed before the measured run:

1. Qdrant breaks RRF score ties arbitrarily: repeating each EN gold query gave a different fused order for
   143 of 150 queries (30 with a different set at the cut), dense results being identical. `order_fused()`
   now fetches `fused_limit + 16` and sorts by (RRF rounded to 9 dp, best dense cosine, point id): 0 of 150
   differ on repeat.
2. The eval retriever now loads the same drug-synonym expansion as production `build_retriever()`.

### Abstention (confidence gate)

Logistic regression on `dense_top`, `lexical_coverage`, `sparse_agreement` plus a per-language bias (EN
baseline), threshold set at <= 8% in-sample false abstention, evaluated by stratified 5-fold cross-validation
(held-out rates; the shipped model is refitted on all 450 rows). Written to
`manifests/ausculta_corpus_2026_11_16_seed1.retrieval.json` (`calibrated_on` points at the report).

| Lang | abstain on out-of-corpus (n) | abstain on answerable (n) |
|---|---|---|
| EN | 1.000 (54) | 0.073 (96) |
| FR | 1.000 (54) | 0.104 (96) |
| AR | 1.000 (54) | 0.094 (96) |
| all | **1.000** (162) | **0.090** (288) |

Fitted weights: `dense_top` 26.4, `lexical_coverage` 8.5, `sparse_agreement` 0.09 (effectively unused);
threshold 0.870. Before calibration (the shipped default gate) the same hybrid run abstained on only 52% of
out-of-corpus questions and 0% of answerable ones.

Degraded mode (embedding API unavailable, lexical-coverage rule): abstains on 95% of out-of-corpus and 25%
of answerable hybrid queries; without the English rewrite it abstains on 100% of FR/AR answerable queries
(BM25 cannot match an FR/AR question against English passages).

## Decisions

1. **Rerank OFF.** On the 61 answerable queries the reranker actually scored (30 sampled per language, 90
   reranked, 0 failures), nDCG@8 went from 0.9858 (RRF-only) to 0.9818 with rerank: **-0.39 points**, far
   from the +3 points required. It would also add ~630 ms p50 / ~950 ms p95 and one Decisions call per turn.
   `rerank: false` in the stored retrieval config; the code path stays for re-measurement.
2. **Hybrid RRF (k = 60) with English rewrites for FR/AR stays the production mode for now**, with the
   calibrated confidence gate above. It meets every retrieval gate with margin except false abstention
   (0.090 vs 0.10).
3. The English rewrite is kept: it costs FR/AR about 1 nDCG@8 point in ranking on this set, but it is what
   lets BM25 and the degraded-mode rule work for FR/AR questions at all.

## Open points (re-measure on the full build)

- **Dense-only beat hybrid on this gold set** (nDCG@8 0.987 vs 0.969, R@20 1.000 vs 0.990). The seed has
  one source (MedlinePlus, English) and paraphrased LLM questions; exact identifiers (drug brand names in
  BDPM, French HAS terms) where BM25 should help are not represented. Rule for the full build: if dense-only
  still beats hybrid by >= 1 nDCG@8 point overall with no language worse on R@20, switch `mode` to `dense`
  and keep BM25 only for degraded mode.
- **Recalibrate after the full build.** The gate was fitted on a 720-chunk index; with ~111k chunks
  out-of-corpus questions will find closer neighbours, so `dense_top` shifts. `python -m rag eval` on the new
  collection refits and writes its own `<collection>.retrieval.json` before promotion; a collection without
  one runs the uncalibrated default gate.
- False abstention is close to the gate (0.090 overall, FR 0.104). Out-of-corpus abstention at 1.000 is a
  ceiling on an easy set: the out-of-corpus questions are off-domain (cooking, sport, travel, IT) or about
  fictional conditions and drugs. There are no "near-miss" questions (a real medical topic the corpus does
  not cover); add some before the full-build eval.
- Gold rows are unreviewed and single-relevant; R@20 is at or near ceiling, so one miss moves a language by
  0.010. The seed gold stays usable on the full build (chunk ids are deterministic
  `doc_id#section_id#ordinal`, the MedlinePlus file is unchanged since the seed build, and the 720 seed
  chunks are embedding-cache hits in the build plan), but on ~133k chunks other sources may answer the same
  question, which single-relevant scoring counts as a miss. Add full-build gold (`python -m rag gold`) that
  covers the French sources (BDPM, HAS) and have a reviewer sample it.
- Re-run the rerank ablation if a paid tier or a different reranker becomes available; the decision rule is
  unchanged (+3 nDCG@8 points).
