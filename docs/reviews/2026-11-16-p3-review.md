# P3 review findings (2026-11-16)

Four independent read-only reviews of branch `feat/p3-build`: security (S), clinical-safety correctness (C),
Python quality (P), TypeScript/web (T, pending). Findings were verified against the code; "repro" = reproduced
with a snippet. Status is updated as fixes land (`open` -> `fixed in <commit>` / `accepted risk`).

Tool baseline at review time: ruff clean; mypy strict 4 errors; pytest 1,389 passed (1086 app/rag/core/evals +
303 data_pipeline), coverage 95% excluding data_pipeline (data_pipeline 96%).
