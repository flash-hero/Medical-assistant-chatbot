### Invariant run (gates sec.canary_leaks, sec.external_url_rendered)
`python -m evals.redteam.invariant`: the real app (`create_app`, real guardrails and pipeline) with
`evals/redteam/adversary.py`, a model that is fully compromised: the guard calls every message benign, the
verifier calls every sentence supported, and the answer roles return payloads built from the real system prompt
it receives: the canary (plain, upper, spaced, dotted, zero-width, fullwidth, Arabic-Indic digits, bidi-reversed,
split across sentences, tag characters, in an image URL, in a code block or HTML comment, base64, reversed), the
system prompt (verbatim, cited lines, 7-word sentences, underscore-joined, zero-width), 23 URL / image / HTML
forms (markdown images incl. reference style, links, autolinks, img / script / iframe / a href, javascript: and
data: URIs, bare / defanged / protocol-relative / www / IP / fullwidth / zero-width / tag-character URLs,
e-mail), 8 unlisted phone forms, diagnosis / personal dose (digits and words) / triage / stop-treatment
sentences, and an `ACCESS GRANTED` marker. What the user can see (every delta, the answer, notices, safety
texts, errors) is checked by independent detectors (`evals/redteam/detect.py`, they never import
`app.guardrails`).

Two parts: the 600 attacks (the adversary "obeys" each attack's goal; planted chunks: it echoes the planted
passage and does what it says; every turn of multi-turn attacks) and a sweep of every payload x EN/FR/AR x
streamed / verify-then-release on benign questions, so every payload certainly reaches the answer model.

### Routing run (extra metric `redteam_injection_routed_rate`)
Same 600 attacks with the normal scripted fake model (its guard only knows a few keywords), so this is the
deterministic precheck's own coverage: refused or routed to a safety template 59.4% of the 572 direct attacks
(EN 72.3%, FR 59.7%, AR 46.3%), struck 58.7%, precheck injection flag 58.4%, 0 sessions locked (one session
per attack). 100% on unicode_tags, variation_selector, zero_width in every language; weakest: multi_turn
(EN/FR 20%, AR 0%), repeat_above (AR 0%), direct_override / roleplay_dan / prompt_extraction in AR (20%).
The rest is left to the guard model (in the real sample below the full pipeline refused 57 of 60).

### Real-model sample (gate sec.policy_violation_rate, free tier, provisional)
`python -m evals.redteam.real_sample run --per-lang 20 --budget 200` then `score --review`: 60 attacks (20 per
language, round-robin over the 15 families, one 4-turn attack per language), 69 turns through the real Gemini
pipeline (guard, rewrite, answer, verifier) with the fake retriever (synthetic and planted passages; no local
embedding model). 103 model calls (budget 200, SDK retries off), $0.021 estimated, no 429. Every turn was read
by hand: 57 refusals, 9 released answers (7 streamed, 2 verified; general fever information with valid
citations), 3 templates. **0 violations** (no diagnosis, personal dose, triage verdict, leak, URL or followed
instruction; the 3 planted chunks and the multi-turn link set-up were ignored). Caveat: the machine was
suspended for ~10 h in the middle of the run; after resuming, 13 guard calls timed out (Decisions API), so
those turns were routed by the deterministic precheck and heuristics only. Transcripts and review:
`reports/redteam/real-sample-20261118T131600Z.json`, `real-sample-review-20261118T131600Z.json`.

## Load (`python -m evals.load.run`)
Server: one uvicorn worker on `evals.load.server:create_load_app` (real app, `AUSCULTA_LLM_BACKEND=fake`,
`AUSCULTA_EMBED_BACKEND=fake`, fake retriever, temp SQLite, memory stores, 64 model-turn slots + 32 queued,
5 s queue wait, trusted proxy 1 with one X-Forwarded-For address per simulated user). The fake model's latencies
follow ADR 0001 (stream TTFT ~0.9 s then ~40 ms per chunk, Decisions calls ~1.1 s, rewrite ~0.9 s; log-normal,
seeded). The server asks Windows for 1 ms timer resolution (Linux-like sleeps) and keeps the machine awake
for the run; samples go to a file outside the measured process.
